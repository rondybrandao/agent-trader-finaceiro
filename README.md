# B3 ML

Projeto de exploração e Machine Learning utilizando dados históricos
de cotações da B3.

## Objetivos

- Entender o formato COTAHIST da B3
- Realizar análise exploratória dos dados
- Limpar e transformar os dados
- Criar features para Machine Learning
- Definir um problema de previsão/classificação
- Treinar modelos
- Avaliar os modelos respeitando a natureza temporal dos dados
